# 桌宠联调：同一桌，四种不同的接法

2026-11-25 · 使用虚构场景，无真实读者记录。阿里云北京个人测试端点的 `/models` 列出了 `deepseek-v4.1-flash`；下列观察来自它的 `chat/completions`，不是本机规则或示例台词。

## 怎么试

用 `npm run dev:pets` 启动本机开发预览，打开热榜首页 `/`，点右下角的刘看山。输入框上方出现「在线联调」即可直接说话。每次最多生成一只的一个气泡。事实已答完，或上一只问出了读者害怕的地方，就把话头交还；其余可以接话时，点「听另一位接话」才另发一次请求。第二位看到第一位的实际回答，没有要补的也可以不说。可以随时插话或收屋，无需把整桌听完。

- **模型回复**：自由聊天的台词来自模型；问文中事实时，模型只挑依据，气泡显示通过逐字核对的原句。选段没有答案就明说。
- **本机回复**：对已带入的原句或评论进行核对、说晚安、关闭便签等，不需要调用模型。
- **话头留给你**：这是一次正常停顿，不是假装动物说了话；记录不多一条，也不会出现断线提示。
- **本机兜底**：本次模型失败，保留读者原话，由本机接住；第二位没接上时只提示失败，不凭空填一个发言。

本机开发配置见 [环境示例](../.env.example)，将三项 `PET_CHAT_TEST=1`、`PET_CHAT_MODEL=deepseek-v4.1-flash` 和个人密钥放在忽略的 `.env.development.local`。与原文章导读的 `LLM_*` 分开。每次最多带上这桌当前共享范围内的七条在线发言（含当前一句）。默认不带文章；点「把这段放上桌」本身也不发请求，聊原文时才附上可见的标题与原句（最多 160 字）。只想倾诉、寻求支持或诉说害怕时，两位都不附选段，也不重送之前的原文核对问答，除非读者明确想结合该选段获得支持；是否有授权与这轮是否需要它，是两件事。撤下、明确换话题、收屋或刷新会清掉授权和可发送的旧发言。本机仍能回看原聊天。不会附送书架、全文、评论、便签或手账。`/trial` 不调用此接口；生产构建不启用个人测试密钥。

## 实测后改了什么

| 观察 | 改动 | 同组虚构对话复测 |
| --- | --- | --- |
| 柴犬喊「冲就完事了！」，还夸读者没提过的耐心。第一轮完整聊天又把「决定去」当成「已经走进去」。 | 打气不等于催行动；不补写结果，不以大哥或啦啦队的口气说话。 | 「你决定去上课了，这就够了。我在你这边。」没有接任务或追问。 |
| 猫头鹰正确指出「被嫌慢」只是猜测，却又主动提出教人练开口。 | 只在读者开口要练时才陪练；分清已知和推测就可以停。 | 同一场景中指出「怕他嫌你慢，是你猜的，还没发生」，没有再开练习。 |
| 不点名时，读者从「先听我说」改口要练一句，猫有时继续替柴犬教方法。 | 点名优先；明确的陪听、陪练、求小步、权衡、收束交给相应角色；闲聊和第二位仍由模型选，不轮询。 | 同一段无点名对话中，从猫接住门口的紧张，切到柴犬陪练「刚才那句我没听清，能再说一遍吗？」。 |
| 旁听阅览室话题时，第二只容易复述「延长开放时间」，或误把读者当管理员。 | 建议针对事情本身；下一只补一个条件或适用边界，不评论上一只的措辞。 | 柴犬提出延时或还书箱；猫头鹰接着区分了「能还书」与「能留下来读」，并指出值班条件。 |

**换题复测，不只重放同一句。** 多次抽样时，柴犬曾又把「决定去」说成「还是去了」。因此被点到时只加载本人的角色卡，给「只要打气」单独限定为表达支持，而不复述结果。换成「想投稿，邮件还没发」时，模型答：「你是想寄的，这份心我支持。不急着有结果，我在你这边。」换成「想试陶艺课，还坐在家里」，它也没有编成已到课堂。

**还要观察**：另一轮浏览器实测中，猫头鹰把读者明说的「晚班赶不上」反说成猜测；看山也偶尔替读者写结论（如「你心里就亮堂了」）。已区分「读者给定的情境」和「仍需核实的条件」，并提示看山不宣布对方已释然。猫有时仍把感受的原因猜得过实。下轮让读者故意纠正它，看看它能否接受纠正而不再解释读者。一次复测不等于角色永远稳定。

## 重放

- [四份人设、选人及接话规则](../src/lib/pet-personas.ts) 是下一轮调词的入口。
- `npm run observe:pets`：在已启动的本机开发预览上发送八次测试请求（第二位可以留白）；消耗个人测试额度，只发送脚本里的虚构对话。
- `python scripts/verify_pet_chat.py`：无额度的移动尺寸浏览器检查，覆盖收屋、改口、限流兜底、手动接话和试用隔离。加 `--live` 才实际调用模型。
- `npm run test:companion`、`npm run build`、`npm run test:companion:api`：不需要个人模型密钥。

阅读时长、选段内外盲问、收屋和并发恢复的实测与复跑方法见[阅读到群聊压力验收](reading-pressure.md)。

同一篇试读里中途改口、事实核对与不抢话的逐轮实测见[三种读者意图](handoff-intent.md)。
