# 看山伴读 · 毛茸茸圆桌｜目标原型 V6.1

**用这版对齐什么：** 同一个看山，如何从阅读页窗沿来到桌边；三位伙伴怎样走进水彩小屋；聊天怎样接住用户自己的话，再把一件小事存下来。这是一套交互与动效目标，不是正式产品的接口实现。

## 先体验一遍

1. 下载[单文件原型](../../public/previews/roundtable-v6.1/index.html)，双击 `index.html` 用浏览器打开。无需安装、联网或填写密钥。两篇文章都可以单独体验。
2. 点阅读页右下角写字的刘看山。先看他的笔，再看圆窗、地板右边和门口。伙伴就座后点「开聊」，或让小屋自然进入第一句。
3. 选「听下一句」。猫头鹰说完，试着自己写 **我想找回上周的那条笔记** 并发送。再听柴犬与看山接话。文字不会发给任何服务。
4. 接过掌控卡，点「我拍板，收进手账」。回到阅读页后，点右上「猫咖手账」能找到它。卡片上的出处能带回对应的本地文章。
5. 进行到一半也可以关闭小屋。同一篇里再点看山会接着聊，不强迫重看进场。想评审动效，点窗沿下面的「重看入场」，不会丢掉刚才的发言。

**另外一条走法：** 换到「收藏之后」，在圆桌选「总觉得读不完」。柴犬接住的困扰和最后的小纸条都会改变。没有落入两种主题的自由文本走通用回应，不假装理解所有输入。

**只评审这次发言立绘修正**：可从同一 HTML 的 `#portraits` 入口直接到呼噜猫第一句，或播放[发言立绘慢速交棒](media/03-speaker-handoff.gif)。普通入口保留原来的入屋速度。

## 画面以什么为准

- **集合全景：以 544×704 小屋为构图基准。** 猫头鹰落在左侧圆窗，抱杯的猫留左前景，红围巾看山居中写字，柴犬在右侧门旁，桌子为前后遮挡层。已有的人设、围巾、杯、眼镜、双爪和书不重绘。
- **同屋开聊，而非换皮弹窗。** 保留屋顶、话题和木屋背景。全景收到上方，当前角色占左、气泡占右。记录和输入是可以选择、滚动、编辑的真实界面，不烤进图或视频。
- **全景对齐坐标**（参考画布 544×704，原点在左上）：标题中心约 `(272,101)`；话题条约 `(35,138,475,59)`；房间约 `(33,204,479,271)`；摘记约 `(33,484,479,115)`；底栏约 `(33,622,479,49)`。底栏在集合时是明确的「开聊」，进入对话后换为可编辑输入。
- **发言表演**：猫抱杯接情绪，不提建议；猫头鹰扶镜回原文；柴犬抬爪替你说；看山停笔，把讨论收成一个可做的小动作。不做四张同节奏一起摇晃的头像。

## 动效时序（毫秒）

第一组以**点看山**为零点。几条轨迹有重叠，不要把时长首尾相加。

| 从哪到哪 | 时间窗 | 运动与验收点 |
|---|---:|---|
| 桌宠 → 回应 | 0–247 | 笔尖停下、眼睛抬起，书页不漂，两只爪不丢。待机本身只动手腕和铅笔，不上下漂移整个人。 |
| 窗沿 → 小屋 | 184–847 | 以实际窗沿的矩形做起始位置，先撑开墙体，室内、标题与摘记分层显现。不是从屏幕中心放大一个弹框。 |
| 看山 → 桌边 | 234–919 | 以书的可见边界对齐；看山带着书移动并稍微缩小，落到桌面时再低头，避免两端各闪出一只看山。 |
| 猫头鹰 → 圆窗 | 725–1,879 | 远处小轮廓沿弧线拍翅放大；落窗收翅、轻压一下即止。 |
| 呼噜猫 → 左前景 | 922–2,035 | 从画面右边跑进来，经过桌前；四足跑动、减速，最后抱杯落坐。 |
| 护短柴犬 → 右前景 | 1,193–2,409 | 门外远点起步，按透视放大，影子跟着脚底；最后半步收住。不要匀速放大一张贴纸。 |
| 全员 → 等你开聊 | 2,580 | 角色和构图都落稳。可以跳过入场；常规动效下，集合停留约 2,560 ms 后进入第一句；减少动态时只等用户主动开聊。 |

后续以**对应的用户操作**为零点：

| 触发 | 时间 | 画面和交互结果 |
|---|---:|---|
| 开聊 | 镜头 820 ms；第一位完全入画约 1,320 ms | 先收近全景，再让呼噜猫在同一背景中显现。气泡文字整句可读，上一张猫不会透在它的脸或茶杯后面。 |
| 听下一句 | 1,120 ms | 前一位用 410 ms 退场，完全退去才换图，后一位用 710 ms 入场。气泡本身不消失；名字和文字同步换。每位只在入画后用约 1.7 秒轻轻动一次，然后安定，不循环切姿势。同一位补一句时只换文字。用户决定何时继续，无最短强制等待。 |
| 插话 | 用户决定 | 选一个建议或发送自己的原话。提前插话会记入记录，猫头鹰讲完原文后由柴犬承接。中文输入法选择候选字时不会误发。 |
| 接过卡 | 510 ms | 最后一句仍短暂可见，小纸从看山手边展开；纸面先到、文字后清晰。**此时尚未收藏**。 |
| 我拍板 | 710 ms，再留约 300 ms 落章 | 纸卡沿弧线飞向屋内手账页角，随后出现手账条目、日期和主题猫印记。只有拍板才写入。同卡再次拍板只翻到已存页。 |
| 关闭 | 548 ms | 从当前进度收尾；伙伴退出或纸页淡下，小屋沿原路径折回窗沿，看山接笔。开门中也能按 Esc，中断后不会自己又开。 |
| 再次点开 | 360 ms | 直接续到本篇的上一句话、选择、卡面或手账；当前页面内按文章分别记住，不重播整段入场。 |

## 状态、边界与验收

**主路径**：阅读待机 → 打开 → 集合 → 猫发言 → 猫头鹰发言 → 用户插话 → 柴犬发言 → 看山收口 → 用户决定 → 掌控卡 → 收藏／手账 → 收回阅读。右上手账也可以直接打开空态或已存条目。

- **原型数据边界**：两篇示例阅读与对白均为本地内容；引用逐字来自对应示例，绝非线上知乎检索或模型回复。这版覆盖「从阅读到手账」的交互，不包含热榜、在线搜索、登录或跨设备同步。移植时请接回正式项目的阅读轨迹、真实原帖、引文校验和服务返回；不要把示例台词搬进生产兜底。
- **存储边界**：讨论进度和未发的草稿只保留在本次打开的页面里。已拍板卡片存在当前浏览器本地（独立键 `fluffy.prototype.v6.journal`）；浏览器拒绝保存时退回本次会话，条目上会说明。不同浏览器、移动文件或无痕模式的留存不能当作同步承诺。
- **键盘／减少动态**：支持 Enter 打开或发送，Tab 在屋内移动，Esc 收起并把焦点还给入口。系统开启减少动态时直接落到稳定画面，无飞跑、无强制自动开聊；所有功能仍可使用。
- **验收过的情形**：桌面完整走通；在开场多个时间点取消；跳过与主动重播；提前插话、两种建议和自由输入；按文章续聊；二次拍板不重存；刷新读取两张卡；存储不可用；390×844 与 360×640 触屏尺寸；无外部请求。浏览器验证使用 Microsoft Edge，本包未声称做过全部浏览器真机测试。
