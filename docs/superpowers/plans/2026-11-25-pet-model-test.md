# 桌宠真模型联调计划

**目标**：在现有热榜首页的看山小屋里测试四位伙伴，不新增聊天页。设计依据：[意图优先小屋](../specs/2026-11-24-intent-first-cabin-design.md)。Next 16 服务端路由 + 现有 Room/Book 状态；沿用一套美术。

- [x] 模型边界：先验证阿里云 `/models` 和一次虚构提问；为 `/api/roundtable/chat` 编写请求、角色、接话和失败路径测试。仅在显式开启的本机联调模式使用个人凭据，限制输入，不与文章导读的端点或密钥混用。
- [x] 接回首页：用相同的读者发言逻辑记录插话，等待中可以改口或收屋；只有该桌最后一句仍然匹配才收下模型回复。点「听另一位接话」才再请一位。离线试用、文章核对、便签保持原有路径。
- [x] 用同一组虚构场景实测猫、猫头鹰、柴犬、看山和两位接话。记录真实的偏差、修改提示词并复测。跑离线用例、接口、类型、构建及浏览器测试；不把外部额度消耗放进日常回归。
