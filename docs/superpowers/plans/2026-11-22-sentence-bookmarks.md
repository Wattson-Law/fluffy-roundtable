# 一句话书签 · 实施与验收

**目标**：在正在读的回答里亲手夹一句，讨论时不丢原意，下次仍能回到这一处。保留整篇开桌、旧手账和原有动效。

**边界**：正文属于来源；评论是别人说的话；聊天是读者自己的。只传主动选中的公开正文和该回答的有限上下文，不传聊天或整本记录。保存时保留来源、位置和前后文。便签不展示原文或私聊，只回到同一桌；已收卡、主动拒绝、输入中或后台均不催。

1. 在 `src/lib/bookmarks.ts` 和 `scripts/companion.test.mjs` 先验证晚于第 1500 字、重复原句、切换书签、丢失原文和旧存档。小屋按回答及选区分开，整篇旧键不变。
2. 在回答卡增加划选和手机/键盘逐句挑选；小屋、手账共享原段视图。来源已加载则定位，找不到时显示明确标记的当时摘录，不偷换成相似句。
3. 在正式分析及本地试读中让猫头鹰引用被选的那句话，柴犬只引用本回答实际取得的读者评论，没有就明说。真实接口拒绝与正文对不上的选区，区分缓存；便签只回访尚未收卡的对话。
4. 回归整篇/选句、刷新、键盘/窄屏、低动效、便签冷却与清空阅读后的手账。验收有/无精选评论两篇真实回答；注明真实数据获取、服务授权和测试替身的边界。五人试用需真人另行参与，不以自动测试冒充。
