# 总设计稿 v1.0：正式小屋收口与验收计划

以已确认的 [总设计稿](../specs/2026-11-24-intent-first-cabin-design.md) 为准，沿用现有热榜、阅读页和右下角小屋。旧提案里的角色辩论、给用户定性不覆盖新稿。保留原美术、聊天和手账，不公开发布测试凭据。

- [x] §2–3：读者纠正猜测，接真实纠正而不复述先前假设；点名/支持/实际困难/收尾、待机→进屋→慢速换人回归。
- [x] §4：本页阅读与永久书架分开；读者明说的少数关键谈话形成四只共享的本机记忆，可查看、更正、禁止主动问、忘记；隔月可问但不声称今天仍然如此。屏幕外不露私事。不从阅读、文章、他人、动物的猜测记忆。
- [x] §4：短念头只由读者主动留；打开先看念头，继续聊需另一个动作；不覆盖引文书签或手账。
- [x] §5：既有知乎服务的榜首、换题、限定范围、原帖、无榜降级；旁听不轮询四位，只有同意继续才自动，输入/收屋/后台停止。
- [x] §6：在正式页面验证两位读者的记忆对照、一个月、可撤回；同时跑失联/限流/挤压恢复、旧版和离线试用。真实五人试用与真实上游、部署状态分开，不伪造反馈。
