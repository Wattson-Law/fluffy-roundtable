# 总设计稿 v1.0 · 可试版验收

2026-11-25。对照[确认稿](superpowers/specs/2026-11-24-intent-first-cabin-design.md)，这次交付的是**原知乎阅读首页上的桌宠和小屋**，不是第二个聊天站，也不是已部署的公共服务。

## 三分钟走一遍

1. 本机启动 `npm run dev:pets`，打开 [一页笔记](http://127.0.0.1:3100/?sample=weekend-notebook)。停留到「看山已记下」，再点窗沿的看山。顶部「阅读记录」能找到原帖；关页再打开，记录还在，但小屋默认不带昨天的文章。
2. 在小屋说「我想去读书会，只是不敢」，再改口「不用分析，给我打打气吧」。观察的是**改口后第一句**，不要求四个伙伴全发言。若主动想留下一个念头，点「记个念头」，确认文字后保存。在书架打开只看，不发消息。
3. 说「你们挑一条新闻聊聊，我听着」。只递一题，不等于同意连播。可以说「没兴趣」「聊点科技的」或「你们接着聊，我听着」。没榜时改为「我来出题：公共图书馆该不该晚点关门？」；未经证实的事会按假设聊。

## 哪些目标有了证据

| 设计要求 | 本版表现 | 如何复核 |
|---|---|---|
| §1–2：读者改口优先 | A–F 各自可开局，支持与问办法不是一回事。点名、亲口纠正、逐字问原文走不同路径。有些第二句就该不说。 | `npm run test:companion`；`verify_intent.py`；[同篇五轮对照](handoff-intent.md) |
| §3：伙伴和话头 | 看山守窗、三位进屋、慢速交接和固定气泡保留。输入不启动旧导读；收屋/新发言后，不接晚到的旧回复。模型失联用有标记的本机回复，不冒充模型。 | `verify_companion.py`、`verify_pet_chat.py`、`verify_handoff_intents.py`；桌面、390 和 360 像素宽度 |
| §4：本次阅读 ≠ 书架 | 一次停留/展开即记，重读去重，书架最多 100 篇；圆桌只取本页实际读过的至多 5 篇同来源材料。刷新/后台保留；关页或另开标签不自动续旧桌。明确选原帖、旧聊天或书签，才回那一桌。 | `session-reading.test.mjs`、`verify_single_article.py`、`verify_reading_discussion.py`、`verify_bookmarks.py` |
| §4：读者说过的事 ≠ 猜测 | 四只共享有限的、带日期和原发言标识的本机小记，不存文章链接、选句或人格画像。允许更正、禁问、忘记。普通旧聊天最多七天；关键小记可以隔月问近况。只有猫能主动递邀请，屋外不露内容，至少空闲五分钟，24 小时最多一次，没回不追问。 | `shared-memory.test.mjs`、`verify_shared_memory.py`：同文两位模拟读者、跨月、四只继承更正、撤回、失焦草稿 |
| §4：自己的念头 | 手动输入或亲自确认，至多 80 字；原文链接自选，文章书签与念头互不覆盖。预览只读，「继续聊」只预填，删除不删原文或聊天。 | `reader-thoughts.test.mjs`、`verify_proposal.py` |
| §5：有来由的旁听 | 接现有知乎热榜/搜索。榜首、站内范围、换题、上一题、读者出题都在同一桌。能核对的摘录或评论与伙伴自己的建议分开。开连续旁听前不自动换题；动笔、输入法组字、切后台、换桌、收屋会停。搜索只带读者提出的简短范围，不带聊天。 | `listening-topics.test.mjs`、`verify_proposal.py`：用可重复的站内数据检查来回切题、原帖、传闻、延迟到达和无榜 |
| §6：按读者目标评价 | 匿名双桌试用可从网页和单文件离线包进入。换人、略过、关页与本机匿名汇总均已用**合成输入**验过。真人对“那句是不是我想听的”的判断不能由脚本代答。 | [试用包与主持人说明](reader-trial/README.md)；`verify_trial.py` 同时测网页与实际 ZIP |

## 修过的三个具体问题

- 读者说「不是怕上台，我是怕别人觉得我没读懂」。首轮真实模型还在复述“上台”。现在不改本机原话，只在这个明确纠正的请求里把肯定的半句交给模型。复测的猫猫从「你怕的是别人觉得你没读懂，可你还是想去分享」接起，没有再提上台或追问原因。另一条虚构输入提到学修钟和末班车，柴犬先支持决定，再表示愿意一起看这个难处，没有擅自安排交通。本次两条复测都来自 `deepseek-v4.1-flash`，不是压力测试结果。
- 只读过求职文章的读者，不会因此被认作找工作；亲口谈过的读者，隔月回来也要**重新等满五分钟**，不是打开页面几十秒就来问。旧窗留下的邀请不把旧文带进新窗。说「还记得我上次搬家的事吗」时，没有这条记忆就直说没有，不拿唯一的求职记忆硬答。
- 从文章转去听新闻时，先前同意共享的文章不再随下一条私聊外发；小屋顶端和「附上原文」也切到**当前话题**。从传闻问「证实了吗」不会误去引用桌底下那篇旧文章。

**交付前复核又拦下了三种串题。** 曾经同读甲、乙两篇后，从书架只选乙篇也会把甲篇交给导读。现在「和它们聊这篇」只带选中那篇；想取回原来的整桌，请选「过去的聊天 → 继续这段聊天」。先记养猫、再谈求职，读者接着说「忘了这件事」时，现在删的是刚刚提示的求职小记，不是早先的养猫记录；指代不清时不删除。即使手动共享了文章，换成「帮我列一份明天买菜的清单」也不附原文，连上一回的引文答复也不附；「今晚想睡了」直接在本机道晚安。`verify_single_article.py` 在正式首页捕获请求、检查本机记忆，分别复核这三项。

## 工程验收与外部边界

- `npm run typecheck`、`npm run build`、`npm run test:companion:api`：类型、生产构建及生产接口回归。个人模型在生产模式关闭；由单独的文章分析流程处理主动请求的导读。本机打开在线联调后，当前主动发送的话可能按界面提示交给模型，但不会自动附上书架、念头或长期记忆。
- `npm run test:companion`：104 项通过。`npm run stress:pets`：本机上游替身接受 160 次常态、320 次突发和 16 次恢复阶段请求（共 496）。覆盖过载、超时、限流、无原句与没有第二句；不是线上吞吐量或质量指标。
- `python scripts/stress_reading.py --readers 4 --parallel 2 --burst 8`：4 个独立模拟读者交错阅读/换题，共 84 次请求、40 个晚回复场景、16 个故障回退。没有拿真实知乎或模型配额压测。
- 浏览器验收使用 Edge 和 Python Playwright。构建后在第二个终端启动 `npx next start --hostname 127.0.0.1 --port 3127`，在各个脚本传 `--base http://127.0.0.1:3127`。普通回归不要传 `--live` 或 `--public`。离线包通过 `npm run pack:trial` 重新制作；用 `python scripts/verify_trial.py --channel msedge --base http://127.0.0.1:3127 --zip docs/reader-trial/window-seat.zip` 复核实际交付文件，而不是仅测源码。
- **上游现状**：本次本机实查热榜接口返回降级、0 条，没有将替身或编辑室文章当作今日榜首。已有的[模型人设实测](pet-model-test.md)和本次改口抽查来自低量、串行的虚构输入；不宣称任意说法都能听对，也没有经由 GitHub 开放个人额度。
- **交付止点**：正式功能以设计 v1.0 为界。尚未进行五人真实试用或公网部署；原草案里与最终决定冲突的画像定性、强制对立和四人轮询没有重新加入。下一步请五位读者独立试两桌，只交回匿名勾选：改口后有没有接对、有没有重复追问、需不需要再解释一次。
