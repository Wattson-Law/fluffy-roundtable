## 不用账号，怎样试

1. 在项目目录运行 `npm run dev`，打开 <http://localhost:3100>。点窗沿正在写字的刘看山。没有阅读记录时直接坐下；若桌上有文章，也可以选「不带文章，去窗边坐坐」。没必要先按「开聊」。
2. 说「帮我分析一下」→「我想去，就是有点怕」→「没听懂师傅教的，我不敢再问」→「不用练了，给我打打气吧」。留意**下一句**，不是末尾有没有一句安慰。也请试试从最后一句开局，或点名请猫头鹰鼓励你。
3. 改成「想去，给我加油吧。就是十点下班，末班车九点半」：柴犬可以留下可选的帮助，不该直接规划通勤。再问「明天能先做什么」，才谈下一步。中途收屋再开，应停在原句。
4. 去 <http://localhost:3100/?sample=weekend-notebook> 夹一句原文，问「这句话是什么意思」。没有可靠解释时就说不知道；回到谈心，不再挂无关的评论、其他文章来源或行动卡。

## 做了什么，没做什么

| 这轮可以验证 | 边界 |
| --- | --- |
| 分开判断愿不愿意、具体卡点、所需回应；读者可以点名或纠正 | 本地中文规则，不是开放域语义模型；含蓄表达、讽刺、复杂多意图仍可能听错。线索只在本桌续用，不构成跨桌人物画像。 |
| 支持、陪听、解释、行动可以切换；插话后废弃旧导读；卡片回执不会在打字或收屋后插入 | 明确选择的文章导读仍是手动播放。没有自动生成一整场旁听节目；收卡不等于存下读者的新念头。 |
| 不读文章可聊；只展开桌宠不提交阅读正文；选真实导读/按篇按句开桌才提交相关摘录；自由输入不发往模型 | 真实来源需已取得。样文为编辑室原创；没有为演示伪造榜首、评论或知乎引文。 |
| 空闲邀约同桌一次，屋外无私事；普通收屋不增加聊天条数 | 当前主动问候仍基于七天内真实聊天，不能跨月回访。关闭页面不会清掉读者书架；单独的会话阅读层是后续工作。 |

## 这次实际跑过的检查（2026-11-24）

- 本机 24 项行为检查全部通过，生产构建、类型检查和带本机替身的生产接口检查通过。
- 在正式构建上跑过三个浏览器回归脚本：桌面、390 像素和 360 像素窄屏；验证了改口、输入法、准备导读/卡片时插话或收屋、原句回看、便签和重新打开原桌。窗边私聊的测试没有发出包含对话的网络请求。

## 怎么复验

- `npm run test:companion`：既有阅读、书签与打扰边界，加上总设计稿 A–F、点名、否定/纠正、未知原因不连问、晚到回执等。
- `npm run typecheck`、`npm run build`、`npm run test:companion:api`：类型、生产构建、使用本机替身的生产接口。最后一项不是在线模型或知乎测试。
- 启动网页后运行 `python scripts/verify_intent.py --channel msedge`（可加 `--base URL`）；`verify_companion.py`、`verify_bookmarks.py` 同样支持指定地址。覆盖桌面和窄屏、输入法、导读与原文复核、切换意图、延迟回执、折叠重开。使用 Python Playwright；测试中的读者及对话均为虚构。

## 五人试用（待执行，无用户数据）

**已有独立入口：** [离线试用包和主持人收卡说明](../reader-trial/README.md)。读者请走 `/trial` 或解压后的离线页，而不是带有示例台词和持久聊天记录的正式首页。此处提纲保留作对照，真人反馈尚待收集。

让读者用自己的说法，不展示上面的标准台词。每人先试「分析中途改口」，再试「只要鼓励但有现实困难」；挑一次输入或收屋中断，最后由读者自己决定还要不要聊。每场只记：改口后的第一句是否接对、是否重复追问/硬讲完、是否需要再解释。不要抄录私人原话。

如果求打气却被劝衡量、只读文章却被猜私人近况，或收屋后谈话仍自行增长，该场景就要返工。结尾只问：「你改口后，它们接下来说的，是你当时想听的吗？」**自动化通过，不代表五位读者已经认可。**
