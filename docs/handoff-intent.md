# 同一篇笔记，三种说法：什么时候该把话头还给读者

2026-11-25 · [本机试读《一页笔记，什么时候才算读完？》](http://127.0.0.1:3100/?sample=weekend-notebook) · 现有热榜首页和看山小屋。下面是一次全新 Edge 会话里的虚构对话，不是用户记录。

## 为什么不能只改人设提示词

读者说：「这篇里抖出来几张便签？算了，我现在只想吐槽。我对着同一页看了三遍，还是烦。」最早的版本认出了“想被听见”，却仍走事实核对，把“三张便签”的原句贴给读者。第一次改为按说话先后识别请求后，猫猫答：「书里抖出三张便签，光是收拾这些就够折腾人了。」它不数了，却把作者收拾桌子的经历当成读者的。

改的是给伙伴的材料，不只是措辞。**放上桌是允许用，不是每句都要用。** 倾诉、打气和说害怕时，从这一轮请求剔除标题、选段和识别出的旧原文问答；读者当前的原话、跟这次交谈有关的同桌发言不改写。只有读者明确请伙伴结合已放上桌的段落安慰自己，才保留它。单说「我昨天用这段原文做了张卡」不算。原聊天没被删，授权也没有因此撤销；稍后问事实，仍能用同一段。

## 修后，在同一桌真实说了什么

模型 `deepseek-v4.1-flash`。选段已经放上桌，全程不用重新授权。下面五次在线请求串行；最后显示在屏幕上的文本与“模型决定选哪句”、“界面固定提示”、“本机查找”分开记。

| 读者说或做 | 界面实际结果 | 这一轮的材料与话头 |
| --- | --- | --- |
| 先问数量，随即改口只想吐槽 | 呼噜猫：「同一页看三遍还烦，那这几遍真的挺磨人的。便签不想数就先不数，停在这口气上就好。」 | 没附选段，没回答数量，也没把收拾桌子说成读者做过的事。仍提了一嘴读者自己说过的“便签”。 |
| 点「听另一位接话」 | 保留猫的气泡，显示「话头留给你，不急着回。」 | 第二位没有开新气泡。本机记录条数不变，不报错，也不再重复邀请。 |
| 「作者从书里抖出来几张便签？我只想核对这个数字。」 | 猫头鹰：「能核对的是这一句：『周六收拾桌子，我从书里抖出来三张便签。』」 | 这次附上已授权的选段。模型选依据，程序核对后把原句放进气泡；不让别的动物再解释数字。 |
| 「只想核对带『满页箭头』的那句。」 | 本机证据卡：「第一张抄了一整段话，第二张画了满页箭头。」 | 正文就有答案，**零模型请求**，这一步不算在五次之内。 |
| 「我想去读书会分享这页笔记，就是有点不敢。」 | 呼噜猫：「想去，又有点不敢，这两种感觉是真的同时待着。那份不敢，是想到哪一幕时会冒出来？」 | 没再送原文或上一轮查到的答案。只问了一个问题，等读者说，不让第二只抢答。 |
| 「狗狗，先别分析，也不用问为什么，给我打打气就好。」 | 护短柴犬：「你是想去分享的，这就够了。我站在你这边。」 | 没追问，没列行动清单，也没把“想去”说成“已经去了”。 |

## 怎么复核

- `python scripts/verify_handoff_intents.py`：在运行中的本机预览执行，默认文章源和模型都是测试替身。除了台词，还核对每次实际发送了什么、聊天记录是否多了一条、按钮是否消失。只有主动加 `--live` 才使用真实模型；完整一趟五次聊天请求、零次文章分析。这轮另外两次修前/修中单句观察不计入这五次。
- `npm run test:companion`：50 项通过。覆盖先问事实再改口、先吐槽再问事实、「作者建议先做什么」而不是「请给我建议」、未经授权不带原文，邀请第二位时有合适补充或留白两条路径，以及看山听懂「把刚才弄清的那件事留一句就好」后不再开一轮。
- `npm run stress:pets`：496 个**本机模拟请求**（160 常态、320 突发、16 恢复）；突发同时发 16 个，模拟模型最多同时处理 4 个，恢复阶段没有拥挤拒绝。限流和超时是刻意注入的情形，不是真实模型的吞吐量。
- `python scripts/stress_reading.py --readers 4 --parallel 2 --burst 8`：4 个互相隔离的读者，两两同时在开发预览操作；84 次模拟请求，40 条作废的慢回复未挂错桌，16 次故障按预期在本机回应。另复核了类型检查、正式构建和构建后接口；个人测试模型不在正式构建开启。

**还想听真人判断的地方：** 猫没有再数便签，但仍复提了读者已经放下的东西。是否比到「那这几遍真的挺磨人的」就停更好，不能靠正则或一次模型回复下结论。下轮让读者纠正一次猫的猜测（例如「不是怕上台，我是怕别人觉得我没读懂」），看它是接住新的那句话，还是又开始替人解释。
